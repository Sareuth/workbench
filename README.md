# Workbench

A React + TypeScript project for learning and experimenting with modern React development.

## Current status

Current milestone: v0.2.0

Workbench currently includes:

- React components and component composition
- TypeScript
- Task list rendering
- Adding tasks
- Toggling tasks complete and incomplete
- Deleting tasks
- Inline task editing with Save and Cancel
- Focused edit mode that temporarily disables unrelated controls
- Task filtering with All, Open, and Completed views
- Local task persistence with `localStorage`
- Accessible form controls and task actions
- Behavioural testing with Vitest and React Testing Library
- Basic dark-theme styling

Workbench starts with an empty task list when no saved data exists.

## Tech

- React
- TypeScript
- Vite
- Vitest
- React Testing Library
